Its break-glass is the hypervisor console, not a local account. **Live 2026-10-02**: both gates verified — the dashboard reports `auth_required: true` / `["self-hosted"]`, and `hermes.bnei.dev/api/status` 302s to authentik instead of answering. ## Format

Each runbook has the structure:
1. Goal
2. Prereqs (Infisical auth, IPs assigned, hosts reachable)
3. Steps (exact commands)
4. Verification (sanity checks, expected output)
5. Rollback (how to undo)
